# AI-Powered Biometric Attendance System

A unified monorepo containing the multimodal attendance platform powered by Computer Vision, Voice Biometrics, Streamlit, and Supabase, accompanied by a dedicated web landing page.

## Repository Structure
- **app/**: Streamlit application running live camera detection, facial embeddings, voice biometrics, and Supabase database interactions.
- **landing/**: Lightweight Flask web application serving as the marketing showcase and documentation portal.
